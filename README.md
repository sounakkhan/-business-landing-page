Elevate Academy | Multi-Academic Stream Coaching Institute Landing Page

A modern, highly responsive, and feature-rich landing page built for Elevate Academy, a premier multi-stream coaching institute. This project is designed to communicate value clearly, guide prospective students through academic streams (Science, Commerce, Arts, and Foundation), build trust through social proof, and capture leads via an interactive consultation booking form.

🎯 Objective

The primary goal of this project is to create an authentic, high-conversion, production-ready website for a coaching institute that:

Clearly showcases distinct academic streams (Science, Commerce, Arts & Humanities, Foundation).

Provides an intuitive user experience with smooth navigation and mobile responsiveness.

Implements robust client-side form validation to ensure high lead quality.

Adheres to industry best practices in web typography, spacing, and accessibility.

💻 Tech Stack

Markup: HTML5 (Semantic Structure)

Styling: CSS3 (Custom Properties, Flexbox, CSS Grid, Responsive Media Queries)

Interactivity & Validation: Vanilla JavaScript (ES6+)

Icons: FontAwesome v6.4

Typography: Plus Jakarta Sans (Google Fonts)

Hosting / Deployment: Vercel / Netlify / GitHub Pages

✨ Features Implemented

Sticky Navigation Bar: Fluid desktop menu with a responsive hamburger drawer for mobile devices (<768px).

High-Impact Hero Section: Compelling value proposition, dual call-to-action buttons, verified trust metrics, and floating status cards.

Multi-Stream Academic Grid: Dedicated cards for Science (JEE/NEET), Commerce (CA Foundation/CUET), Arts (Civil Services), and Foundation (Grades 8–10).

Why Choose Us Section: Highlights expert faculty, personalized mentorship, adaptive testing engines, and doubt clearing.

Success Stories: Testimonial grid showcasing verified student ranks and percentiles.

Interactive Contact & Booking Form: Fully validated via HTML5 attributes and custom JavaScript logic with real-time error handling and a success confirmation state.

🚀 Setup or Run Instructions

To run this project locally on your machine, follow these simple steps:

Clone or Download the Repository:

git clone https://github.com/your-username/business-landing-page.git


(Or download and extract the ZIP folder containing index.html and style.css).

Open the Project Folder:
Make sure both index.html and style.css are saved in the exact same folder.

Run Locally:

Double-click on index.html to open it directly in any modern web browser (Chrome, Safari, Firefox, Edge).

Recommended: If using VS Code, install the Live Server extension, right-click index.html, and select "Open with Live Server".
